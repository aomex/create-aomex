# AsyncAPI

> WebSocket Channel 文档由 `src/channels` 源码生成，与实现同步。

## Capabilities

| 模块         | 说明                                    |
| ------------ | --------------------------------------- |
| **Channels** | `*.channel.ts` 声明事件、payload、emit  |
| **AsyncAPI** | 由 `@aomex/asyncapi-generator` 自动生成 |

## Quick Start

```bash
pnpm start
# 打开本页即可浏览 Channel 契约
```
