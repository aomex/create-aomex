# API

> Type-safe API powered by aomex：路由、中间件、校验、文档一站式可观测。

## Capabilities

| 模块           | 说明                       |
| -------------- | -------------------------- |
| **Routers**    | 声明式路由与参数校验       |
| **Middleware** | 链式组合，可观测可复用     |
| **OpenAPI**    | 由源码自动生成，与实现同步 |

pnpm dev
